لبو با صورت لومو (نسخه‌ی آزمایشی v3)
=====================================
چشم‌ها از پروژه‌ی Lumo (github.com/Aymo/Lumo) پورت شدن و اندازه‌هاش از صفحه‌ی ۴۶۶ به ۳۶۰ پیکسل کوچیک شدن.
همه‌ی دستورهای USB مثل قبل کار می‌کنن، پس برنامه‌ی لپتاپ (pc\laboo.py) دست نخورده.

bin\flash.bat          ریختن این صورت روی برد (اول run.bat رو ببند)
laboo_face\            سورس کامل؛ فقط face.cpp عوض شده + heart_lumo.h اضافه شده
                       face_v2.cpp.txt = همون face.cpp قبلی، برای مقایسه
faces_lumo_preview.png همه‌ی حالت‌ها، از روی همین کد رندر شده

برگشت به صورت قبلی:  archive\faces_2026-10-27\v2_current\flash.bat
