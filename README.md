# تادا — ربات صورتکی با ESP32-S3-Touch-LCD-1.85C

```
 [برد ESP32]  صورت متحرک + لمس + میکروفون
      │  کابل USB (صدا می‌رود، دستور حالت چهره برمی‌گردد)
 [لپ‌تاپ]  Whisper (صدا→متن)  →  Claude (مغز + حافظه)  →  صدای فارسی از بلندگوی لپ‌تاپ
```

## محتویات پوشه

| مسیر | چیست |
|---|---|
| `firmware/laboo_face/` | کد برد (Arduino). درایورهای نمایشگر/تاچ/میکروفون از نمونه‌ی رسمی Waveshare برداشته شده؛ کتابخانه‌ی اضافه‌ای لازم نیست |
| `pc/laboo.py` | برنامه‌ی لپ‌تاپ |
| `pc/config.yaml` | همه‌ی تنظیمات (کلید API، صدا، حالت گوش دادن و…) |
| `pc/memory.json` | حافظه‌ی ربات؛ بعد از اولین گفتگو ساخته می‌شود |

---

## قدم ۱ — ریختن کد روی برد

1. **Arduino IDE** را نصب کن. در Boards Manager بسته‌ی **esp32 by Espressif** نسخه‌ی **3.0.2 یا جدیدتر** را نصب کن.
2. فایل `firmware/laboo_face/laboo_face.ino` را باز کن.
3. از منوی Tools این‌ها را تنظیم کن:

| گزینه | مقدار |
|---|---|
| Board | ESP32S3 Dev Module |
| USB CDC On Boot | **Enabled** |
| USB Mode | Hardware CDC and JTAG |
| Flash Size | 16MB (128Mb) |
| PSRAM | OPI PSRAM |
| Partition Scheme | 16M Flash (3MB APP/9.9MB FATFS) |
| Core Debug Level | None |

4. برد را وصل کن، پورت را انتخاب کن و Upload بزن.
   اگر آپلود شروع نشد: دکمه‌ی **BOOT** را نگه دار، یک‌بار **RESET** بزن، BOOT را رها کن و دوباره Upload کن.

بعد از آپلود باید صورت ربات بیاید، پلک بزند و به اطراف نگاه کند؛ حتی بدون لپ‌تاپ. با انگشت رویش بکشی چشم‌ها دنبالش می‌کنند.

## قدم ۲ — آماده کردن لپ‌تاپ

1. **Python 3.11 یا 3.12** را از python.org نصب کن (تیک *Add python.exe to PATH* را بزن).
2. روی `pc/install.bat` دوبار کلیک کن (چند دقیقه طول می‌کشد).
3. کلید API کلاد را از **console.anthropic.com** بگیر (جدا از اشتراک claude.ai است) و در `pc/config.yaml` جلوی `api_key:` بگذار.
4. `pc/run.bat` را اجرا کن.

> **بار اول** مدل Whisper (حدود ۱.۶ گیگ) دانلود می‌شود. اگر لپ‌تاپ ضعیف است یا تشخیص کُند بود، در `config.yaml` مقدار `local_model` را `medium` یا `small` کن (سریع‌تر، ولی دقت فارسی کمتر).
>
> Claude، دانلود Whisper و صدای edge-tts هر سه اینترنت لازم دارند و از ایران ممکن است فیلترشکن بخواهند. بعد از دانلود، Whisper کاملاً آفلاین کار می‌کند.

## قدم ۳ — استفاده

**صدا کردن با اسم (حالت پیش‌فرض):**
- بگو **«تادا!»** → برمی‌گردد و می‌گوید «جانم؟». حلقه‌ی سفید دور صفحه یعنی دارد گوش می‌دهد؛ سؤالت را بپرس.
- یا یک‌جا بگو: **«تادا، ساعت چنده؟»** → مستقیم جواب می‌دهد.
- بعد از هر جواب چند ثانیه منتظر می‌ماند تا بدون صدا کردن اسمش ادامه بدهی.
- حرف‌هایی که اسمش در آن‌ها نیست را نادیده می‌گیرد. در پنجره‌ی برنامه با `(heard, not for me: …)` نشانشان می‌دهد تا ببینی چه شنیده.
- اگر اسمش را بد می‌فهمد، همان چیزی که شنیده را به `wake_words` در `config.yaml` اضافه کن.
- حتی بدون لپ‌تاپ هم به صدا واکنش نشان می‌دهد: با صدای بلند ناگهانی جا می‌خورد، وقتی کسی حرف می‌زند ابروهایش را بالا می‌برد، و با صدا زدن از خواب بیدار می‌شود.

| کار | نتیجه |
|---|---|
| **یک ضربه** روی صفحه | بدون صدا کردن اسمش گوش می‌دهد |
| ضربه **وسط گوش دادن** | «حرفم تمام شد» |
| ضربه **وسط حرف زدن ربات** | ساکتش می‌کند |
| **نوازش** (کشیدن انگشت روی صورت) | ذوق می‌کند و چشم‌هایش قلبی می‌شود |
| **نگه داشتن** انگشت | تعجب می‌کند؛ هر کاری در حال انجام است را قطع می‌کند |
| تایپ در پنجره‌ی برنامه + Enter | سؤال متنی (Enter خالی = شروع گوش دادن) |
| `/facts` | نشان می‌دهد تا الان چه چیزهایی درباره‌ات یاد گرفته |
| `/clear` | پاک کردن گفتگوی اخیر (چیزهای یادگرفته می‌مانند) |
| `/emo angry` | امتحان حالت‌های چهره |

**چهره:** همه‌چیز سفید است: چشم‌های بلند، ابرو و دهان. حالت‌ها: neutral، happy، sad، angry، surprised، love (چشم قلبی)، confused، sleepy.
**عصبانیت:** چشم و دهان قرمز می‌شود، دهانش به حالت داد زدن با دندان‌های تیز درمی‌آید، صورتش می‌لرزد و علامت‌های فحش (#!⚡) بالای سرش می‌آید. صدایش هم تندتر و بلندتر می‌شود. (مثلاً مسخره‌اش کن یا بگو «عصبانی شو!»)

حالت‌های دیگر `mode` در `config.yaml`: `tap` یعنی فقط با ضربه گوش می‌دهد؛ `always` یعنی به هر حرفی جواب می‌دهد.

## «یادگیری» چطور کار می‌کند؟

خود مدل Claude با حرف زدن آموزش نمی‌بیند. تادا یک **حافظه‌ی بلندمدت** دارد:
- هر بار که چیز ماندگاری درباره‌ات بفهمد (اسمت، علاقه‌ها، آدم‌های زندگی‌ات، یا وقتی می‌گویی «یادت باشه…») آن را در `memory.json` می‌نویسد. در پنجره‌ی برنامه هم `+ learned:` چاپ می‌شود.
- هر بار این دانسته‌ها را به Claude می‌دهد، پس در روزهای بعد هم یادش هست.
- گفتگوهای قدیمی خودکار خلاصه می‌شوند تا حافظه بی‌نهایت بزرگ نشود.
- بگو «فلان چیز را فراموش کن» تا پاکش کند. می‌توانی `memory.json` را با Notepad هم ببینی و ویرایش کنی.

## مشکلات رایج

| مشکل | راه حل |
|---|---|
| `board not found` | کابل USB باید دیتا داشته باشد (فقط شارژ نباشد). اگر چند برد ESP وصل است، در `config.yaml` پورت را دستی بگذار (مثلاً `COM5`). مانیتور سریال Arduino IDE را هم ببند |
| میکروفون برد کار نمی‌کند | برنامه خودش به میکروفون لپ‌تاپ سوئیچ می‌کند؛ یا دستی `mic_source: laptop` بگذار |
| بدون حرف زدن ضبط شروع می‌شود | `min_level` را بیشتر کن (مثلاً 600) |
| اسمش را نمی‌فهمد | `wake_model` را `medium` کن یا کلمه‌ای که شنیده را به `wake_words` اضافه کن |
| جمله‌ات را وسط کار قطع می‌کند | `end_silence` را 1.5 کن |
| صدا پخش نمی‌شود (`TTS failed`) | اینترنت یا فیلترشکن را بررسی کن |
| تشخیص فارسی ضعیف است | `local_model: large-v3-turbo` بگذار، یا `engine: api` با Groq (رایگان، `whisper-large-v3`) |
| صفحه سیاه است | تنظیمات قدم ۱ را دوباره چک کن، به‌خصوص PSRAM و USB CDC On Boot |

## توسعه‌ی بیشتر

پروتکل USB ساده است و بالای `laboo_face.ino` توضیح داده شده. هر برنامه‌ای می‌تواند با فرستادن خط‌هایی مثل `E happy`، `S thinking`، `L 50 -20` یا `M 70` چهره را کنترل کند. برای حالت چهره‌ی جدید، یک ردیف به `PRESETS` در `face.cpp` اضافه کن.
